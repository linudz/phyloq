# Cercopithecidae: PSS versus absolute-trait assignments

This table defines a clade-, species-, and pool-size-matched control for the
PSS-informed Cercopithecidae benchmark. It retains the same 19 species used by
approach 08 and compares two fixed-side assignments:

- `PSSGroup`: assignment derived from PSS-selected directional shifts;
- `AbsoluteTraitGroup`: the nine highest relative-brain-mass species assigned
  to FG and the ten lowest assigned to BG.

The absolute-trait split is completely separated. Its lowest FG value is
1.3199587652633 (*Papio papio*) and its highest BG value is 1.30765946241004
(*Trachypithecus francoisi*). Six species change sides between assignments:

- BG to FG: *Macaca leonina*, *Macaca maura*, and *Papio papio*;
- FG to BG: *Trachypithecus francoisi*, *T. pileatus*, and *T. cristatus*.

Source table:
`09_cercopithecidae_pss_random_pools.tsv`.

Regenerate the TSV from the pipeline directory with:

```bash
python3 scripts/create_cercopithecidae_absolute_trait_control.py
```

This table drives approach 09. The pooled configuration and its dedicated
one-row manifest are generated by `create_pss_benchmark_configs.py`.
